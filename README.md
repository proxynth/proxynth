## About

Nearly a decade of backend engineering across digital publishing and e-commerce, EV charging, online communities, event platforms and multi-product SaaS. Across these domains, my work has centered on integrations, migrations, data flows and dependable production systems.

More recently, I have worked on payment and subscription domains, cross-product services, cloud infrastructure and traceable data workflows. I use coding agents with tests, static analysis and human review around generated code.

## Areas of focus

- **Backend systems** — PHP/Laravel and Go, service boundaries and integrations
- **Reliable workflows** — asynchronous processing, failure handling and traceability
- **Payments** — webhooks, idempotency, retries, replay and reconciliation
- **Software quality** — testing, maintainability and pragmatic architecture
